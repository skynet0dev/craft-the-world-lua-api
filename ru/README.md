# Craft the World — Lua API

Восстановленная документация по Lua API игры **Craft the World (2014)**.

> Эта документация восстановлена напрямую из бинарного файла игры (`CraftWorld.exe`, построен на **sol2 + Lua 5.3**). Официального API не существует — всё здесь извлечено реверс-инжинирингом: порядок кода регистрации, CTTI-сигнатуры `usertype_metatable`, вшитые в PDB, и дизассемблирование привязочных функций.

## Что можно делать

Craft the World предоставляет небольшой, но мощный Lua API, который позволяет:

- **Генерировать и изменять мир** — ставить блоки, заливать комнаты, создавать воду и существ при генерации уровня.
- **Спавнить объектов и мобов** — выбрасывать предметы, боссов и интерактивные объекты в точных координатах.
- **Управлять ИИ мобов** — писать логику патрулирования и перемещения для кастомных существ.
- **Реагировать на события** — запускать скрипты при падении сундука, старте уровня или событии дропа.

## Четыре типа

| Тип | Конструктор | Назначение |
|-----|-------------|-----------|
| [`World`](api/world) | `World.new()` | Чтение и изменение карты, спавн, запрос позиций. |
| [`Vector`](api/vector) | `Vector.new(x, y)` | 2D вектор/точка из float с математическими операторами. |
| [`GameObjectManager`](api/gameobject) | *(получается через движок)* | Создание объектов и поведений по имени. |
| [`MobLogic`](api/moblogic) | `getLogic()` | Управление ИИ моба (патруль, точки назначения). |

## Глобальные функции

Несколько свободных функций доступны без какого-либо объекта, например [`getEventPosition()`](api/globals#geteventposition), [`getLevel()`](api/globals#getlevel), [`isOwnerDLC_monsters()`](api/globals#isownerdlc_monsters).

## Где лежат скрипты

| Папка | Роль |
|-------|------|
| `scripts/` | Глобальная логика игры — `game.lua`, `generate.lua`, скрипты событий. |
| `data/Components/AI/` | Скрипты ИИ мобов — по одному на поведение существа. |

Подключить общий код можно так:

```lua
require "scripts/common"
```
